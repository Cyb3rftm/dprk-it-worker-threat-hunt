# DPRK IT Worker Threat Hunting Project

## Overview

This project documents a threat hunting initiative focused on identifying indicators associated with suspected DPRK IT worker activity within a corporate hiring process.

The objective was to proactively identify suspicious applicants using cyber threat intelligence, OSINT, and log analysis techniques.

---

## Skills Demonstrated

- Cyber Threat Intelligence
- Splunk

- MITRE ATT&CK
- OSINT
- Risk Assessment
- Security Operations

---

## Technologies

- Splunk
- Workday Logs
- Threat Intelligence Feeds
- OSINT Sources

---

## Project Summary

A detection process was developed to identify suspicious job applicants using known DPRK-linked indicators.

Weekly automated searches compared applicant information against known indicators from threat intelligence reporting.

Potential matches were reviewed and escalated to appropriate stakeholders.
